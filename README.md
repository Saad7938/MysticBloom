# Mystic Bloom

## Introduction
Mystic Bloom is a 3D farming game where players manage crops while dealing with insect threats.  
It solves the problem of traditional farming games by adding action and strategy through insect management.

## Features
- Interactive plant growth
- Random insect spawning with tap-to-kill feature
- Drag-and-drop selling system for plants
- Main menu with start, exit, and sound options

## Tech Stack
- Unity 3D
- C# scripts
- Unity UI

## How to Run the Project
1. Open the project in Unity Editor
2. Open the `MainScene` in the Scenes folder
3. Press the Play button to start the game
